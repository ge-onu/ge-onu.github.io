# 이미지 자산

## home-icon.svg

사용자가 제공한 흑백 홈 아이콘을 벡터 트레이싱해 저장한 자산입니다.
상단의 홈 이동 버튼에서 사용하며 원본 비율을 유지합니다.

적용 위치:
- `index.html`
- `projects/mealplanning/index.html`
- `projects/kubernetes-lab/index.html`

## kubernetes-logo.svg

사용자가 제공한 Kubernetes 로고/워드마크 이미지를 벡터 트레이싱해 저장한 자산입니다.
`assets/kubernetes-lab-cover.svg`에도 같은 벡터 자산을 사용해 홈 카드와 Kubernetes 상세 Hero에 반영합니다.

손상된 base64-in-SVG 방식은 더 이상 사용하지 않습니다.
