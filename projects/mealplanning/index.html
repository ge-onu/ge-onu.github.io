Running인데 새 배포는 안 되던 이유

이 항목은 프로젝트 종료 후 Runtime을 점검하면서 확인한 사례입니다. 당시 프로젝트 중 해결한 장애로 표현하지 않습니다.

Existing podsRunning

Restart 0, cached image로 계속 동작

RegistryUnreachable

새 이미지 Pull 불가

New deployFailed

배포·재스케줄링 시 문제 노출

왜 숨었나

기존 Pod는 Node에 남아 있던 이미지로 계속 실행돼 겉으로는 정상처럼 보였습니다.

어디서 드러났나

새 배포처럼 Registry 접근이 필요한 순간에만 실패가 나타났습니다.

추가 문제

주기적 Canary가 실패 신호를 만들고 있었지만 그 Canary 실패 자체에는 Alert가 없었습니다.

Running ≠ Deployable. 현재 상태뿐 아니라 다음 변경을 수행할 수 있는지도 운영 상태의 일부라는 점을 확인했습니다.
