Service

Selector와 Endpoint가 실제 Pod를 가리키는지 확인했습니다.

Ingress

Host/Path Rule과 Service Port가 맞는지 확인했습니다.

DNS

Service 이름 기반 통신이 CoreDNS를 통해 해석되는지 확인했습니다.

Storage

PV/PVC, Local PV, NFS, StatefulSet을 구성하고 PVC가 Pending일 때 바인딩 조건을 확인했습니다.

PVC / PV

요청 용량과 Access Mode가 맞는지 확인했습니다.

StorageClass

어떤 방식으로 PV를 제공하는지 확인했습니다.

Local PV

Node와 Storage가 강하게 묶일 때 Scheduling 제약을 확인했습니다.

NFS

공유 Storage를 PVC에 연결해 상태 저장 워크로드를 구성했습니다.

PVC가 Pending이면 Storage 하나만 보지 않고 PVC·PV·StorageClass·Access Mode·Event를 함께 확인했습니다.

증상마다 명령어를 외우기보다, 먼저 상태와 Event를 보고 확인할 범위를 줄였습니다.
