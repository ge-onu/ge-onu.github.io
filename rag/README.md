# 거누 — 건우에 대한 RAG 챗봇

geonu.site 오른쪽 아래의 거누는 이 사이트에 공개된 기록만 검색해서 답합니다.

| 단계 | 하는 일 | 파일 |
|---|---|---|
| 검색·판정 | BM25 검색, 주장 카드 라우팅, 근거 없으면 거절(closed-world), 기여 범위 판정 | `engine.js` |
| 답변 조립 | 거절 문장, 근거 묶음, 생성 프롬프트, 사실 검사, 생성 없는 답 | `answer.js` |
| 응답 서버 | 엔진 판정 → Gemini가 근거 안에서만 작성(실패하거나 깨진 글이면 다음 모델로 한 번만 다시) → 출력 정상성 검사와 숫자·기술명·금지 표현 검사(어긋나면 한 번 고쳐 쓰고, 그래도 어긋나면 근거 문장으로 답) | `worker/worker.js` |
| 근거 데이터 | 사이트 HTML → chunk 126개, 주장 카드 18개 | `data/`, `tools/bundle.py` |

## 출발점

엔진은 [RAG Retrieval PoC](../projects/rag-retrieval-poc/)의 FROZEN_V2 파이프라인(Python)을 JavaScript로 옮긴 것입니다.
PoC 평가 문항 100개와 추가 문항 10개에서 Python 원본과 출력이 바이트 단위로 같습니다(`chat` 확장을 끈 상태).

배포판에서 바꾼 것은 `tools/build_claims.py`에 이유와 함께 적었습니다.

- 사이트 개편으로 바뀐 근거 id를 다시 연결했습니다.
- 서버리스 문구를 "전환 판정·Lambda 구현"으로 정정했습니다.
- 공개된 학력·지원 직무는 거절하지 않도록 했습니다.
- 서버리스·역할·자격증 카드를 새로 만들었습니다.
- "어떤 프로젝트를 했나요?" 같은 넓은 질문을 위해 프로젝트 목록 카드(`C-PROJECTS`)를 만들었습니다. 홈과 상세 페이지에 적힌 문장만 모았고, 답에는 프로젝트 5개의 상세 링크가 붙습니다.

엔진의 `chat` 옵션은 해요체 질문("써 봤어요?")도 경험 질문으로 읽습니다.

## 평가 (`node rag/tools/eval.mjs`)

| 항목 | PoC 동결 기준 | 배포판 |
|---|---|---|
| 근거 없는 질문 정상 거절 | 12/12 | 12/12 |
| 답할 질문 정상 답변 | 88/88 | 88/88 |
| 답한 질문의 인용 정확도 | 0.989 | 0.989 |
| 경계 질문(부정·적대) | 1.000 | 34/34 |
| 배포 점검 문항 | — | 25/25 |
| 생성 출력 정상성 검사 | — | 14/14 |

PoC 정답 chunk id는 옛 사이트 기준이라, 글자 4-gram이 가장 많이 겹치는 지금 chunk로 옮겨 채점했습니다.
factual/paraphrase R@3는 0.975(39/40)입니다. 남은 1건은 새로 생긴 요약 구역이 상위에 올라온 경우라, 답의 근거는 맞습니다.

## 생성 답의 안전장치

사실 검사는 숫자·기술명·금지 표현만 봅니다. 2026-10-14에 Gemini가 503을 낸 뒤 대체 모델(Workers AI gpt-oss-120b)이 `!`만 700여 개 돌려줬는데, 사실 검사를 그대로 통과해 화면에 나갔습니다.
그래서 다음을 바꿨습니다.

- 출력 정상성 검사(`answer.js`의 `sanityIssues`): 너무 짧은 답, 글자(한글·영문) 비율이 낮은 답, 기호가 30%를 넘는 답, 같은 글자 8번 이상 연속, 같은 기호 40번 초과, 같은 구절 5번 이상 반복을 거릅니다.
- Workers AI 대체 작성을 뺐습니다. Gemini 첫 모델이 실패하거나 깨진 글이면 다음 모델로 한 번만 다시 부르고, 그래도 안 되면 근거 문장으로 답합니다(간단 모드). 모델 호출 전체는 18초 안에서 끝냅니다.
- 브라우저도 같은 검사를 한 번 더 합니다. 서버가 깨진 생성 답을 보내면 브라우저 안의 엔진으로 답합니다.
- 시험: `rag/tools/output_checks.json`(깨진 글 9개·정상 답 5개, `eval.mjs`가 함께 채점), `node rag/tools/test-worker.mjs`(Gemini 응답을 흉내 내어 503·시간 초과·깨진 글에서 간단 모드로 떨어지는지 확인).

## 다시 만들기

```bash
python3 rag/tools/bundle.py          # 사이트 문구를 고친 뒤
node rag/tools/eval.mjs --fails       # 재평가 (실패가 있으면 종료 코드 1)
node rag/tools/test-worker.mjs        # Worker 끝단 시험(모델 응답 흉내)
python3 rag/tools/bundle_worker.py /tmp/geonu-rag.mjs   # Worker 한 파일로 묶기 (또는 rag/worker 에서 npx wrangler deploy)
```

Worker 비밀값은 `GEMINI_API_KEY` 하나입니다. 무료 등급 Gemini 프로젝트(geonu-rag)의 키를 쓰고, 질문 원문은 저장하지 않습니다.
